## ✨ 功能特性

### 🎯 核心功能

| 功能 | 描述 |
|------|------|
| **智能划词翻译** | 在任意网页上选中英文单词、词组或句子，自动弹出翻译结果 |
| **右键菜单翻译** | 选中文字后右键选择"使用单词翻译助手翻译"，方便快捷 |
| **自动记录** | 智能记录所有翻译过的内容，按单词、词组、句子分类存储 |
| **高亮显示** | 已翻译的单词在网页上自动高亮显示，便于识别和复习 |
| **使用统计** | 记录每个单词的使用频率和最近使用时间 |
| **单词详情** | 点击单词卡片查看完整信息（音标、释义、例句、同义词、反义词） |
| **沉浸式学习** | 提供闪卡、测验、拼写三种专业学习模式，配合每日挑战 |
| **智能复习** | 内置类 SRS (间隔重复) 算法，根据掌握程度自动安排复习 |
| **学习记录** | 自动记录学习行为，最近三天单词按时间倒序显示 |

### 📚 学习模式

- **📖 闪卡模式** - 经典的卡片翻转记忆，适合快速复习
- **📝 测验模式** - 四选一测试，通过干扰项加深单词印象
- **✍️ 拼写模式** - 手动输入单词，高强度强化拼写记忆
- **🎯 每日挑战** - 智能筛选待复习单词，直接进入拼写模式进行高强度训练

### 📊 数据管理

- **分类查看** - 主页显示单词、词组、句子、星标单词四个类别的统计
- **智能搜索** - 在记录页面快速搜索特定单词或内容
- **灵活排序** - 支持按使用次数、最近使用时间、字母顺序排序
- **批量操作** - 支持单个删除或清空所有记录

### 🎨 界面设计

- **现代化UI** - 采用毛玻璃效果和渐变背景，视觉体验优雅
- **星空粒子特效** - 学习模式下启用交互式金色星空背景，鼠标跟随点亮节点
- **SVG 图标系统** - 全局采用精细的 SVG 矢量图标，自适应主题颜色
- **动态主题** - 支持多种预设主题和自定义背景颜色，带有动态渐变效果
- **智能配色** - 卡片颜色会根据背景主题自动调整，确保视觉协调
- **响应式设计** - 适配不同屏幕尺寸，提供流畅的用户体验
- **丰富动画** - 悬停和过渡动画效果，提升交互体验

### 🔒 安全优化

- **全站支持** - 支持所有网页的划词翻译，同时对特殊页面（如 GitHub）做了兼容性优化
- **权限最小化** - 仅请求必要的权限，保护用户隐私
- **性能优化** - 限制高亮单词数量（最多50个），减少DOM操作
- **样式隔离** - 使用带前缀的CSS类名，避免样式冲突

## 🚀 快速开始

### 最快的方式（3步）

1. **克隆项目**
   ```bash
   git clone https://github.com/Timcai06/TIMS-project.git
   cd TIMS-project
   ```

2. **打开扩展管理页面**
   - 在Chrome地址栏输入：`chrome://extensions/`
   - 开启右上角的"开发者模式"

3. **加载扩展**
   - 点击"加载已解压的扩展程序"
   - 选择项目根目录（包含 `manifest.json` 的文件夹）

✅ 完成！现在可以在任何网页上使用划词翻译了

## 📦 安装方法

### 方法一：从源码安装（开发者模式）

1. 下载或克隆此项目到本地
2. 打开Chrome浏览器，在地址栏输入 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择包含 `manifest.json` 的项目文件夹

### 方法二：打包安装

1. 在扩展管理页面点击"打包扩展程序"
2. 选择项目根目录，点击"打包扩展程序"
3. 使用生成的 `.crx` 文件安装

## 📖 使用指南

### 基本使用

1. **翻译内容** - 在任意网页上选中英文单词、词组或句子
2. **查看翻译** - 选中内容后会自动弹出翻译结果
3. **访问记录** - 点击浏览器工具栏中的扩展图标

### 记录管理

| 操作 | 说明 |
|------|------|
| **主页概览** | 查看各类翻译内容的统计数量 |
| **详细列表** | 点击对应卡片进入详细记录页面 |
| **单词详情** | 点击单词卡片进入详情界面，查看完整的单词信息 |
| **搜索功能** | 使用搜索框快速定位单词 |
| **排序选项** | 按不同标准重新排列记录 |
| **星标功能** | 标记重要单词便于重点复习 |
| **删除操作** | 移除不需要的翻译记录，支持删除确认 |
| **学习记录** | 点击进入详情界面自动记录学习，右侧显示最近三天学习的单词 |

### 主题设置

- **背景颜色** - 在设置页面选择预设主题或自定义背景颜色
- **动态效果** - 主题带有自动渐变动画，提升视觉体验
- **智能配色** - 卡片颜色会根据背景自动调整亮度和对比度，确保清晰可读

### 架构特点

- **多层缓存** - 内存缓存 + 持久化存储

## ⚙️ 配置说明

### 权限要求

- `storage` - 本地数据存储
- `activeTab` - 当前标签页访问权限
- `host_permissions` - `<all_urls>` 允许在所有网页上使用

### API 密钥配置

在 `extension/background/background.js` 中配置：

```javascript
const API_CONFIG = {
  netease: {
    appKey: '您的应用ID',
    appSecret: '您的应用密钥'
  },
  baidu: {
    appid: '您的APPID',
    key: '您的密钥'
  }
};
```

> 💡 如果未配置密钥，插件将自动降级使用免费的 MyMemory 翻译接口

## 🛠️ 开发与定制

### 环境要求

- Chrome浏览器 (版本88+)
- Node.js 16+
- 基本的Web开发知识

### 开发命令

```bash
# 安装依赖
npm install

# 运行测试
npm test

# 类型检查
npm run type-check

# 构建TypeScript
npm run build

# 运行测试（监听模式）
npm test:watch

# 生成覆盖率报告
npm test:coverage
```

### CSS样式定制

项目采用模块化CSS架构：

1. **全局变量** - 修改 `extension/components/styles/variables.css`
2. **基础组件** - 在 `extension/components/base/*.css` 中调整
3. **复合组件** - 在 `extension/components/complex/*.css` 中定制
4. **页面布局** - 在 `extension/popup/*.css` 中修改
5. **动画效果** - 在 `extension/components/styles/animations.css` 中添加

### 功能扩展

1. 修改 `extension/content/content.js` 自定义翻译逻辑
2. 更新 `manifest.json` 添加新功能权限
3. 修改 `extension/background/background.js` 扩展后台服务
4. 在 `extension/popup/popup.html` 中调整页面结构
5. 使用组件系统快速开发新UI功能

### 主题定制

1. 在 `extension/components/styles/variables.css` 中修改CSS变量
2. 在 `extension/popup/popup.js` 中添加新的主题配置
3. 支持从预设主题中选择或自定义颜色
4. 主题系统基于CSS变量，修改变量即可全局生效
