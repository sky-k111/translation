Word Drawer Accessibility Test

This page tests the accessibility features of the WordDrawerV2 component. Click the button below to open the word drawer and test keyboard navigation, screen reader compatibility, and other accessibility features.

Accessibility Features Implemented

  • ARIA attributes (role="dialog", aria-modal, aria-labelledby)
  • Focus management with focus trap
  • Keyboard navigation (Escape, Arrow keys, Tab)
  • WCAG AA color contrast (≥ 4.5:1)
  • Touch targets ≥ 44x44px
  • Reduced motion support
  • Screen reader announcements

⌨️ Keyboard Shortcuts

Escape Close drawer • ← Previous word • → Next word • Tab Navigate elements • Space/Enter Activate buttons

Testing Instructions

  • Use keyboard only (no mouse) to navigate
  • Test with screen reader (NVDA, VoiceOver, JAWS)
  • Verify focus indicators are visible
  • Check color contrast in both themes
  • Test with browser zoom at 200%
