## 项目概述

### 什么是单词翻译助手？

**单词翻译助手**是一个Chrome浏览器扩展，为英语学习者提供：
- **智能划词翻译** - 在任意网页上选中英文内容，自动弹出翻译
- **自动记录** - 所有翻译过的内容自动保存和分类
- **多种学习模式** - 闪卡、测验、拼写、每日挑战
- **学习分析** - 完整的学习数据可视化和进度追踪
- **现代UI** - 毛玻璃效果、动态主题、粒子特效
- **塔罗牌游戏** - 内嵌的富交互 React 应用

### 核心特点

| 特点 | 说明 |
|------|------|
| **混合架构** | **核心扩展(原生JS)** + **富交互模块(React)** 的双模架构 |
| **模块化架构** | 清晰的模块分层，易于维护 |
| **组件系统** | BaseComponent继承模式 (原生) + React组件 (子项目) |
| **多层缓存** | 内存缓存 + 持久化存储，性能优化 |
| **服务降级** | 翻译服务自动fallback链 |
| **CSP合规** | Manifest V3严格CSP策略，所有资源本地化 |
| **隐私优先** | 所有数据本地存储，无云上传 |

## 架构设计

### 混合架构 (Hybrid Architecture)

项目采用独特的混合架构，结合了原生开发的轻量级优势和现代框架的开发效率。

```
┌─────────────────────────────────────────────────────────────┐
│                   Chrome Extension Host                     │
│                                                             │
│  ┌──────────────────┐   ┌───────────────────────────────┐   │
│  │  Core Extension  │   │   Embedded React App          │   │
│  │  (Native JS)     │   │   (TAROT-main / game.html)    │   │
│  │                  │   │                               │   │
│  │  - Content Script│   │   - React 19                  │   │
│  │  - Background SW │   │   - Tailwind CSS 4            │   │
│  │  - Popup UI      │   │   - Vite Build                │   │
│  └────────┬─────────┘   └───────────────┬───────────────┘   │
│           │                             │                   │
│           │      Shared Storage         │                   │
│           └─────────────┬───────────────┘                   │
│                         │                                   │
│           ┌─────────────▼───────────────┐                   │
│           │    Chrome Storage API       │                   │
│           └─────────────────────────────┘                   │
└─────────────────────────────────────────────────────────────┘
```

### 三层架构 (核心扩展部分)

```
┌─────────────────────────────────────────┐
│         UI Layer (用户界面层)            │
│  popup.html, dashboard.html, game.html  │
└─────────────────────────────────────────┘
                    ↓
        Chrome Storage API (数据持久化)
                    ↓
┌─────────────────────────────────────────┐
│      Logic Layer (业务逻辑层)             |
│  core/content.js, core/background.js    │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│      Service Layer (服务层)              │
│  翻译服务、缓存、事件、性能监控              │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│      External APIs (外部API)            │
│  OpenAI, Netease, MyMemory, Baidu       │
└─────────────────────────────────────────┘
```

### 职责划分

#### Background Service Worker (`core/background.js`)
- **职责**: API调用、消息处理、跨标签页通信
- **权限**: chrome.runtime, chrome.storage, chrome.webNavigation, chrome.tabs
- **特点**: 后台运行、长期存活、可跨标签页通信

#### Content Script (`core/content.js`)
- **职责**: 页面交互、文本选择、高亮显示、DOM操作
- **权限**: DOM操作、chrome.runtime.sendMessage、chrome.storage
- **特点**: 注入网页、直接操作DOM、可访问页面上下文

#### Popup (`popup/popup.js`)
- **职责**: UI展示、数据管理、用户交互
- **权限**: chrome.storage、组件系统
- **特点**: 用户界面、独立运行、不影响网页

#### Embedded React App (`TAROT-main/`)
- **职责**: 提供独立的游戏化体验或复杂交互界面
- **构建**: 源码位于 `TAROT-main/`，通过 Vite 构建后输出到 `popup/assets/`，最终以 `game.html` 呈现
- **特点**: 独立开发环境、现代前端栈、高性能动画

## 数据流

### 翻译流程

```
1. 用户在网页上选中文本
   ↓
2. Content Script 检测到文本选择
   ├─ 检查内存缓存
   ├─ 如果缓存未命中，发送翻译请求到 Background
   │  ↓
   │  Background 接收请求
   │  ├─ 尝试 AI 翻译（OpenAI）
   │  ├─ 失败 → 尝试网易翻译
   │  ├─ 失败 → 尝试 MyMemory
   │  ├─ 失败 → 尝试百度翻译
   │  └─ 返回结果
   │  ↓
   │  Content Script 接收结果
   │  ├─ 缓存到内存
   │  ├─ 保存到 Chrome Storage
   │  ├─ 高亮显示
   │  └─ 显示翻译弹窗
   │
   └─ 如果缓存命中，直接使用缓存结果
```

### 数据持久化流程

```
Content Script / React App
    ↓
chrome.storage.local.set({
  translatedWords: {...},
  userSettings: {...},
  learningProgress: {...}
})
    ↓
Chrome Storage (本地存储)
    ↓
Popup / Dashboard 读取数据
```

## 技术栈

### 核心扩展 (Core Extension)
- **语言**: JavaScript (ES2020+)
- **标记**: HTML5
- **样式**: CSS3 + CSS Variables (原生模块化)
- **架构**: 自研组件系统 (BaseComponent) + 模块化
- **API**: Chrome Extension Manifest V3

### React 子项目 (TAROT-main)
- **框架**: **React 19**
- **语言**: **TypeScript**
- **样式**: **Tailwind CSS 4**
- **构建**: **Vite**
- **动画**: Framer Motion
- **图标**: Lucide React

### 翻译服务
- **主要**: OpenAI API (gpt-3.5-turbo)
- **备选1**: 网易有道开放平台
- **备选2**: MyMemory API
- **备选3**: 百度翻译 API

### 测试工具
- **单元测试**: Jest
- **集成测试**: Puppeteer
- **性能测试**: Lighthouse
- **视觉测试**: 手动验证

## 开发指南

### 添加新功能 (原生部分)

#### 1. 添加新组件

```javascript
// components/complex/my-component.js
class MyComponent extends BaseComponent {
  constructor(props) {
    super(props);
  }
  
  render() {
    // 实现渲染逻辑
  }
}
export { MyComponent };
```

### 添加新功能 (React 部分)

1. 进入 `TAROT-main` 目录
2. 使用 React + Tailwind 开发
3. 运行 `npm run build:extension` 自动构建并同步到扩展目录

### 调试技巧

#### 1. 调试 Background Service Worker
- 打开 chrome://extensions/
- 点击"Service Worker"下的"检查"

#### 2. 调试 React 页面
- 直接在 `TAROT-main` 下运行 `npm run dev` 进行本地开发
- 或构建后在扩展中打开 `game.html`

## 常见问题

### Q1: 如何添加新的翻译服务？
**A**: 在 `services/` 中创建新服务文件，实现翻译接口，并在 `quality_service.js` 中添加到 fallback 链。

### Q2: 修改 React 代码后为什么没生效？
**A**: React 代码位于 `TAROT-main` 子项目中，修改后需要运行 `npm run build:extension` 才能重新构建并复制到扩展目录。

### Q3: 如何处理 CSP 违规？
**A**: 确保所有资源都是本地的；React 项目构建时会自动处理资源引用，确保符合 Manifest V3 的 CSP 要求。
