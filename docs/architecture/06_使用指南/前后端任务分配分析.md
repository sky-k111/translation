## 架构概览

Chrome 扩展采用经典的三层架构：

```
┌─────────────────────────────────────────┐
│          Popup (弹窗界面)                │
│  - UI 展示和交互                        │
│  - 数据管理（读写 Chrome Storage）      │
│  - 不直接调用 API                       │
└─────────────────────────────────────────┘
               ↓ 读取/写入
          Chrome Storage API
               ↑ 读取/写入
┌─────────────────────────────────────────┐
│      Content Script (内容脚本)           │
│  - 注入到网页中运行                     │
│  - DOM 操作和页面交互                   │
│  - 高亮显示、弹窗显示                   │
│  - 调用 Background 进行翻译             │
└─────────────────────────────────────────┘
               ↓ chrome.runtime.sendMessage
          Background Service
               ↑ chrome.runtime.onMessage
┌─────────────────────────────────────────┐
│    Background Script (后台服务)          │
│  - API 调用（翻译服务、AI 服务）        │
│  - 密钥管理                             │
│  - 跨标签页通信                         │
│  - 页面导航监听                         │
└─────────────────────────────────────────┘
```

## 三大组件职责

### 1. Background Script (`core/background.js`)

**核心职责：网络请求和跨标签页通信**

#### 负责的任务

**API 调用**
```javascript
// 调用翻译 API
- translateWithYoudao()      // 网易有道翻译
- smartTranslate()           // 智能翻译（AI + 有道）
- self.aiAnalyze()           // AI 分析
```

**消息监听和处理**
```javascript
chrome.runtime.onMessage.addListener((msg, sender, sendResponse) => {
  // 处理的消息类型：
  - 'SMART_TRANSLATE'      // 智能翻译请求
  - 'AI_ANALYZE'           // AI 分析请求
  - 'YOUDAO_TRANSLATE'     // 有道翻译请求（遗留）
  - 'RUN_TESTS'            // 测试套件
  - 'GET_QUALITY_REPORT'   // 质量报告
});
```

**页面导航监听**
```javascript
// 监听页面加载完成，通知 Content Script 重新高亮
- chrome.webNavigation.onCommitted.addListener()
- chrome.webNavigation.onHistoryStateUpdated.addListener()
- chrome.tabs.onUpdated.addListener()
```

**API 密钥管理**
```javascript
// 从 Chrome Storage 获取用户配置的 API 密钥
async function getYoudaoCredentials()
```

#### 不负责的任务

* DOM 操作
* 页面 UI 展示
* 用户界面交互

### 2. Content Script (`core/content.js`)

**核心职责：页面交互和 DOM 操作**

#### 负责的任务

**页面交互处理**
```javascript
// 文本选择
- handleTextSelection()        // 处理文本选择
- executeTranslation()         // 执行翻译
- handleHighlightClick()       // 处理高亮单词点击
```

**DOM 操作**
```javascript
// 高亮显示
- highlightTranslatedWords()   // 高亮已翻译的单词
- renderPopup()                // 渲染翻译弹窗
- showClickTooltip()           // 显示点击提示框
```

**调用 Background 进行翻译**
```javascript
// 通过 chrome.runtime.sendMessage 调用
chrome.runtime.sendMessage({
  type: 'SMART_TRANSLATE',
  text: text,
  context: context,
  skipAI: skipAI
});
```

**本地缓存管理**
```javascript
// 使用内存缓存（不涉及 Chrome Storage）
- translationCache             // 翻译结果缓存
- phoneticCache                // 音标缓存
- exampleTranslationCache      // 例句缓存
```

**监听 Background 消息**
```javascript
chrome.runtime.onMessage.addListener((msg) => {
  if (msg.type === 'REHIGHLIGHT') {
    // 重新高亮显示
  }
});
```

#### 不负责的任务

* 直接调用外部 API（所有 API 调用都通过 Background）
* 管理 API 密钥
* 跨标签页通信

**学习功能**
```javascript

```

**数据索引和搜索**

* 不调用 Background 进行翻译（翻译在 Content Script 中完成）
* 不操作网页 DOM
* 不调用外部 API

**关键点**: Popup 只负责展示和管理**已存储**的数据，不参与实时翻译流程。

## 通信流程图

### 场景 1: 用户选中文本进行翻译

```
用户操作：在网页上选中文本
    ↓
Content Script: handleTextSelection()
    ↓
Content Script: executeTranslation()
    ↓
Content Script: translateText()
    ├─→ 检查缓存（内存缓存）
    ├─→ 如果缓存未命中
    │      ↓
    │   chrome.runtime.sendMessage({
    │     type: 'SMART_TRANSLATE',
    │     text: text,
    │     context: context
    │   })
    │      ↓
    │   Background: chrome.runtime.onMessage
    │      ↓
    │   Background: smartTranslate()
    │      ├─→ 尝试 AI 翻译（如果启用）
    │      └─→ 回退到有道翻译
    │      ↓
    │   Background: sendResponse({ ok: true, result })
    │      ↓
    │   Content Script: 接收翻译结果
    │      ↓
Content Script: saveTranslation() → chrome.storage.local.set()
    ↓
Content Script: highlightTranslatedWords()
    ↓
Content Script: showTranslationPopup()
```

### 场景 2: 页面加载完成后重新高亮

```
页面加载完成
    ↓
Background: chrome.webNavigation.onCommitted
    ↓
Background: chrome.tabs.sendMessage(tabId, { type: 'REHIGHLIGHT' })
    ↓
Content Script: chrome.runtime.onMessage
    ↓
Content Script: chrome.storage.local.get(['translatedWords'])
    ↓
Content Script: highlightTranslatedWords()
```

### 场景 3: Popup 展示数据

```
用户点击扩展图标
    ↓
Popup 打开
    ↓
Popup: chrome.storage.local.get(['translatedWords'])
    ↓
Popup: buildIndex()（构建搜索索引）
    ↓
Popup: loadHomePage()（显示统计数据）
    ↓
用户浏览单词列表
```

## 消息类型详解

### Content Script → Background

| 消息类型 | 用途 | 参数 | 响应 |
|---------------------|----------------|-----------------------|-------------------------|
| `SMART_TRANSLATE` | 智能翻译请求 | `{ text, context, skipAI }` | `{ ok: true, result: {...} }` |
| `AI_ANALYZE` | AI 辅助分析 | `{ text, context }` | `{ ok: true, result: {...} }` |
| `YOUDAO_TRANSLATE` | 有道翻译（遗留） | `{ text }` | `{ ok: true, result: {...} }` |
| `ERROR_STAT` | 错误统计上报 | `{ service, error }` | 无响应 |
| `RUN_TESTS` | 运行测试套件 | `{ iterations }` | `{ ok: true, report: {...} }` |
| `GET_QUALITY_REPORT` | 获取质量报告 | 无 | `{ ok: true, report: {...} }` |

### Background → Content Script

| 消息类型 | 用途 | 触发时机 |
|-------------|----------------|-----------------------------------|
| `REHIGHLIGHT` | 重新高亮显示 | 页面导航完成、History API 更新 |

## 实际案例解析

### 案例 1: 完整的翻译流程

```javascript
// ===== Content Script =====
// 用户选中文本 "hello"
async function executeTranslation() {
  // 1. 显示加载动画
  showLoadingIndicator();

  // 2. 调用翻译（内部会调用 Background）
  const translationResult = await translateText("hello", context, true);
  //     ↓
  //     translateText() 内部：
  //     ↓
  //     const response = await chrome.runtime.sendMessage({
  //       type: 'SMART_TRANSLATE',
  //       text: "hello",
  //       context: context,
  //       skipAI: true
  //     });

  // 3. 保存到 Chrome Storage
  await saveTranslation("hello", translationResult.translation);
  //     ↓
  //     chrome.storage.local.set({ translatedWords: {...} });

  // 4. 高亮显示
  await highlightTranslatedWords(words);

  // 5. 显示弹窗
  await showTranslationPopup("hello", translationResult.translation, rect);
}

// ===== Background Script =====
chrome.runtime.onMessage.addListener((msg, sender, sendResponse) => {
  if (msg.type === 'SMART_TRANSLATE') {
    smartTranslate(msg.text, msg.context, msg.skipAI)
      .then(result => sendResponse({ ok: true, result }))
      .catch(err => sendResponse({ ok: false, error: err.message }));
    return true; // 保持消息通道开放，用于异步响应
  }
});

async function smartTranslate(text, context, skipAI) {
  // 1. 尝试 AI 翻译（如果未跳过）
  if (!skipAI) {
    try {
      const aiResult = await self.translateWithAI(text, context);
      return { translation: aiResult.translation, source: 'ai' };
    } catch (aiError) {
      console.log('AI translation failed, falling back to Youdao');
    }
  }

  // 2. 回退到有道翻译
  const youdaoResult = await translateWithYoudao(text);
  return { ...youdaoResult, source: 'youdao' };
}
```

## 设计原则总结

### 1. 职责分离

* **Background**: 只做网络请求和跨标签页通信
* **Content Script**: 只做页面交互和 DOM 操作
* **Popup**: 只做 UI 展示和数据管理

### 2. 通信机制

* Content Script ↔ Background: 使用 `chrome.runtime.sendMessage`
* Background → Content Script: 使用 `chrome.tabs.sendMessage`
* 所有组件 ↔ Storage: 使用 `chrome.storage.local`

### 3. 数据流

```
实时翻译数据流:
用户操作 → Content Script → Background → API → Background → Content Script → 用户界面

数据持久化流:
Content Script → Chrome Storage ← Popup（读取和展示）
```

### 4. 为什么这样设计？

1. **安全性**: Background 可以安全地存储和使用 API 密钥
2. **性能**: Content Script 可以直接操作 DOM，无需跨进程通信
3. **隔离性**: Popup 独立运行，不会影响网页性能
4. **可维护性**: 职责清晰，便于调试和维护

---

## 总结

插件的架构设计非常合理，遵循了 Chrome 扩展的最佳实践：

* **Background Script** 作为"后端服务"，处理所有网络请求
* **Content Script** 作为"前端交互层"，处理页面操作
* **Popup** 作为"管理界面"，展示和管理数据
* 三者通过 **Chrome Storage** 和 **Message API** 进行通信

这种设计确保了：

* **安全性**（API 密钥不暴露）
* **性能**（DOM 操作在页面中直接执行）
* **数据一致性**（通过 Storage API 共享数据）
* **可维护性**（职责清晰，易于扩展）

---

**建议**: 如果需要扩展功能，继续遵循这个架构模式，保持职责分离的原则。
