## 概述

### 什么是可访问性？

可访问性（Accessibility，简称 A11y）是指让产品能够被尽可能多的人使用，包括：
- 视力障碍用户（使用屏幕阅读器）
- 听力障碍用户
- 运动障碍用户（仅使用键盘）
- 认知障碍用户
- 暂时性障碍（如手臂受伤）
- 情境性限制（如在阳光下使用）

### 我们的目标

- **Lighthouse 可访问性评分**: ≥ 95
- **WCAG 合规**: 2.1 Level AA
- **支持主要屏幕阅读器**: NVDA、JAWS、VoiceOver

### 核心原则（POUR）

| 原则 | 说明 | 实现方式 |
|------|------|----------|
| **P**erceivable（可感知） | 信息可被用户感知 | 适当的对比度、文本替代、键盘可操作 |
| **O**perable（可操作） | 界面可被用户操作 | 键盘导航、充足的时间、不引发癫痫 |
| **U**nderstandable（可理解） | 信息和操作可理解 | 可读性、可预测性、输入辅助 |
| **R**obust（健壮性） | 可被各种技术解析 | 有效的 HTML、ARIA 属性 |

## ARIA 属性规范

### 1.1 对话框/抽屉

```javascript
// 必需属性
drawer.setAttribute('role', 'dialog');
drawer.setAttribute('aria-modal', 'true');
drawer.setAttribute('aria-labelledby', 'drawerTitle'); // 指向标题元素

// 可选属性
drawer.setAttribute('aria-describedby', 'drawerDesc'); // 指向描述元素
```

### 1.2 按钮

```javascript
// 图标按钮（无文本）
button.setAttribute('aria-label', '关闭单词抽屉');

// 切换按钮
button.setAttribute('aria-pressed', 'false'); // 或 'true'
button.setAttribute('aria-label', '添加星标');

// 禁用按钮
button.setAttribute('aria-disabled', 'true');
button.setAttribute('tabindex', '-1');
```

### 1.3 导航

```javascript
// 导航栏
nav.setAttribute('role', 'navigation');
nav.setAttribute('aria-label', '单词导航');

// 当前页面
navLink.setAttribute('aria-current', 'page');
```

### 1.4 进度指示器

```javascript
// 进度条
progress.setAttribute('role', 'progressbar');
progress.setAttribute('aria-valuenow', '50');
progress.setAttribute('aria-valuemin', '0');
progress.setAttribute('aria-valuemax', '100');
progress.setAttribute('aria-label', '记忆强度');
```

### 1.5 实时区域

```javascript
// 用于动态更新通知
const liveRegion = document.createElement('div');
liveRegion.setAttribute('aria-live', 'polite'); // polite 或 assertive
liveRegion.setAttribute('aria-atomic', 'true');
liveRegion.className = 'sr-only'; // 视觉上隐藏
```

## 键盘导航

### 2.1 必需支持的快捷键

| 快捷键 | 功能 | 适用范围 |
|--------|------|----------|
| `Tab` | 移动到下一个可聚焦元素 | 全局 |
| `Shift + Tab` | 移动到上一个可聚焦元素 | 全局 |
| `Enter` | 激活按钮/链接 | 全局 |
| `Space` | 激活按钮/切换 | 全局 |
| `Esc` | 关闭对话框/抽屉 | 对话框 |
| `← / →` | 上一个/下一个 | 导航组件 |
| `Home` | 跳到第一个 | 列表 |
| `End` | 跳到最后一个 | 列表 |

### 2.2 实现示例

```javascript
// 键盘事件处理
handleKeyDown(e) {
  switch(e.key) {
    case 'Escape':
      this.hide();
      break;
    case 'ArrowLeft':
      this.navigateToPrev();
      break;
    case 'ArrowRight':
      this.navigateToNext();
      break;
    case ' ': // Space
      e.preventDefault();
      this.handlePronunciation();
      break;
  }
}
```

### 2.3 焦点顺序

```javascript
// 确保逻辑焦点顺序
element1.tabIndex = 0; // 第一个聚焦
element2.tabIndex = 0; // 第二个聚焦
// 避免使用 tabIndex > 0
```

## 焦点管理

### 3.1 焦点陷阱（Focus Trap）

对话框打开时，焦点应限制在对话框内：

```javascript
trapFocus() {
  const focusableElements = this.container.querySelectorAll(
    'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
  );
  
  const firstElement = focusableElements[0];
  const lastElement = focusableElements[focusableElements.length - 1];
  
  this.container.addEventListener('keydown', (e) => {
    if (e.key !== 'Tab') return;
    
    if (e.shiftKey && document.activeElement === firstElement) {
      e.preventDefault();
      lastElement.focus();
    } else if (!e.shiftKey && document.activeElement === lastElement) {
      e.preventDefault();
      firstElement.focus();
    }
  });
}
```

### 3.2 焦点恢复

```javascript
show() {
  // 保存当前焦点
  this.previouslyFocused = document.activeElement;
  
  // 显示组件并聚焦
  this.container.classList.add('active');
  this.focusableElements[0]?.focus();
}

hide() {
  // 隐藏组件
  this.container.classList.remove('active');
  
  // 恢复焦点
  if (this.previouslyFocused && this.previouslyFocused.focus) {
    this.previouslyFocused.focus();
  }
}
```

### 3.3 焦点可见性

```css
/* 确保焦点指示器可见 */
*:focus-visible {
  outline: 2px solid var(--accent-gold);
  outline-offset: 2px;
}

/* 不要仅依赖颜色 */
button:focus {
  outline: 2px solid #c9a86c;
  box-shadow: 0 0 0 4px rgba(201, 168, 108, 0.3);
}
```

## 颜色对比度

### 4.1 WCAG 对比度要求

| 级别 | 正常文本 | 大文本 (18pt+) | 图形/UI |
|------|----------|----------------|---------|
| AA | 4.5:1 | 3:1 | 3:1 |
| AAA | 7:1 | 4.5:1 | 3:1 |

### 4.2 项目色彩标准

```css
:root {
  /* 背景色 */
  --drawer-bg-primary: #1a1f2e;     /* 深蓝灰 */
  --drawer-bg-secondary: #232838;   /* 次要背景 */
  
  /* 文字色 - 确保对比度 */
  --drawer-text-primary: #f0f0f0;   /* 12:1 对比度 */
  --drawer-text-secondary: #b8c0d0; /* 7:1 对比度 */
  --drawer-text-tertiary: #9aa4b8;  /* 4.5:1 对比度 */
}
```

### 4.3 对比度计算工具

- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)
- Chrome DevTools 颜色选择器（显示对比度）
- Stark 插件（Figma/Sketch）

## 屏幕阅读器支持

### 5.1 文本替代

```javascript
// 图标必须有替代文本
// ❌ 不好
`<svg>...</svg>`

// ✅ 好
`<svg aria-label="播放发音">...</svg>`

// ✅ 或者
`<span aria-hidden="true">💡</span>
<span class="sr-only">示例</span>`
```

### 5.2 语义化 HTML

```javascript
// ❌ 不好 - 使用 div 作为按钮
`<div onclick="handleClick()">点击</div>`

// ✅ 好 - 使用正确的元素
`<button onclick="handleClick()">点击</button>`
```

### 5.3 表单标签

```javascript
// ❌ 不好
`<input type="text" placeholder="搜索单词">`

// ✅ 好
`<label for="search">搜索单词</label>
<input type="text" id="search" placeholder="输入单词">`

// ✅ 或者
`<input type="text" aria-label="搜索单词">`
```

## 动画减弱支持

### 6.1 检测用户偏好

```javascript
// 检测系统设置
const prefersReducedMotion = window.matchMedia(
  '(prefers-reduced-motion: reduce)'
).matches;

// 在动画前检查
animate() {
  if (prefersReducedMotion) {
    // 跳过动画，直接显示最终状态
    this.element.style.opacity = '1';
    return;
  }
  
  // 执行动画
  this.element.animate(...);
}
```

### 6.2 CSS 实现

```css
/* 减弱动画 */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}

/* 或者针对特定组件 */
@media (prefers-reduced-motion: reduce) {
  .word-drawer,
  .drawer-section {
    transition: none !important;
    animation: none !important;
  }
}
```

### 6.3 癫痫预防

- 避免每秒闪烁超过 3 次的内容
- 避免大面积红色快速闪烁

## 触摸目标

### 7.1 最小触摸目标尺寸

**WCAG 2.1 要求**: 44×44px（AA级）

```css
/* 按钮最小尺寸 */
.drawer-nav-btn,
.drawer-star-btn,
.drawer-action-btn {
  min-width: 44px;
  min-height: 44px;
  padding: 12px;
}

/* 间距 */
.drawer-action-btn + .drawer-action-btn {
  margin-left: 12px; /* 确保触摸目标不重叠 */
}
```

## 测试工具

### 自动化工具

1. **axe-core** - 可访问性测试库
   ```bash
   npm install @axe-core/cli
   axe http://localhost:3000
   ```

2. **Lighthouse** - Chrome DevTools 内置
   - 打开 DevTools → Lighthouse → Accessibility

3. **WAVE** - 浏览器扩展
   - [WebAIM WAVE](https://wave.webaim.org/)

### 手动测试

1. **键盘测试**
   - 拔掉鼠标，仅使用 Tab/Enter/Space/Esc 操作
   - 确保所有功能可用

2. **屏幕阅读器测试**
   - Windows: NVDA (免费)
   - macOS: VoiceOver (内置)
   - ChromeOS: ChromeVox

3. **高对比度模式**
   - Windows: 设置 → 辅助功能 → 高对比度
   - 检查界面是否清晰可见
