# 组件文档

## 一、组件概述

本项目采用组件化开发模式，将现有直接DOM操作代码转换为组件化开发，提高代码复用性和可维护性，统一UI设计风格，支持浅色/深色主题切换。

## 二、组件目录结构

```
components/
├── base/                     # 基础组件
├── complex/                  # 复合组件
├── business/                 # 业务组件
├── layouts/                  # 布局组件
├── content/                  # Content脚本组件
├── background/               # Background脚本组件
├── utils/                    # 组件工具
├── styles/                   # 组件样式
└── index.js                  # 组件总出口
```

## 三、组件工具

### 3.1 BaseComponent

**组件描述**：组件基类，所有组件都继承自该类，提供组件的基础功能，包括props管理、样式注册、事件处理等。

**核心方法**：
- `constructor(props)`：构造函数，初始化组件属性和状态
- `init()`：初始化组件
- `registerStyle()`：注册组件样式
- `setState(newState, callback)`：设置组件状态
- `bindEvent(element, eventName, callback)`：绑定事件
- `unbindEvents()`：解绑所有事件
- `render()`：渲染组件（子类必须重写）
- `update(newProps)`：更新组件
- `destroy()`：销毁组件

**使用示例**：
```javascript
class MyComponent extends BaseComponent {
  constructor(props) {
    super(props);
  }
  
  render() {
    // 组件渲染逻辑
  }
}
```

### 3.2 ComponentRegistry

**组件描述**：组件注册器，用于管理所有组件的注册和创建。

**核心方法**：
- `register(componentName, componentClass)`：注册组件
- `create(componentName, props)`：创建组件实例
- `getComponent(componentName)`：获取组件类

**使用示例**：
```javascript
ComponentRegistry.register('Button', Button);
const button = ComponentRegistry.create('Button', { text: 'Click me' });
```

### 3.3 StyleManager

**组件描述**：样式管理器，用于管理组件的样式注入和主题切换。

**核心方法**：
- `init()`：初始化样式管理器
- `registerStyle(componentName, css)`：注册组件样式
- `setTheme(theme)`：切换主题
- `getCurrentTheme()`：获取当前主题

**使用示例**：
```javascript
StyleManager.registerStyle('Button', '.button { padding: 8px 16px; }');
StyleManager.setTheme('dark');
```

### 3.4 EventBus

**组件描述**：事件总线，用于组件间的通信。

**核心方法**：
- `on(eventName, callback)`：监听事件
- `emit(eventName, data)`：触发事件
- `off(eventName, callback)`：取消监听

**使用示例**：
```javascript
EventBus.on('themeChange', (theme) => {
  console.log('Theme changed to:', theme);
});

EventBus.emit('themeChange', 'dark');
```

## 四、基础组件

### 4.1 Button

**组件描述**：按钮组件，支持多种样式变体、尺寸和图标。

**Props**：
| 属性名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| text | string | '' | 按钮文本 |
| type | string | 'primary' | 按钮类型（primary, secondary, danger, success） |
| size | string | 'medium' | 按钮尺寸（small, medium, large） |
| disabled | boolean | false | 是否禁用 |
| onClick | function | null | 点击事件回调 |
| icon | string | '' | 图标类名 |

**使用示例**：
```javascript
const button = new Button({
  text: '点击我',
  type: 'primary',
  size: 'medium',
  onClick: () => {
    console.log('Button clicked');
  }
});
```

**特点**：

- 渐变卡片效果
- 流畅的过渡动画
- 圆形进度条
- 支持左右滑动切换

- 词形变化显示
- 释义和例句展示
- **可访问性支持**（ARIA、键盘导航、焦点管理）
- **性能优化**（内存泄漏修复、缓存机制）
- **动画减弱支持**（prefers-reduced-motion）

**架构说明**：
> **注意**：当前版本为独立类实现，不继承 BaseComponent（历史原因）。未来版本将重构为 BaseComponent 子类以统一架构。

**Props**：
| 属性名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| containerId | string | 'wordDrawerContainer' | 容器ID |
| onClose | function | null | 关闭事件回调 |
| onStar | function | null | 收藏事件回调 |
| onDelete | function | null | 删除事件回调 |
| onNavigate | function | null | 导航事件回调（prev/next） |

**核心方法**：
- `show(wordData, index)` - 显示单词抽屉
- `hide()` - 隐藏单词抽屉
- `navigateToNext()` - 显示下一个单词
- `navigateToPrev()` - 显示上一个单词
- `toggleFavorite()` - 切换收藏状态
- `handleDelete()` - 删除当前单词
- `destroy()` - 销毁组件（清理事件、动画、资源）

**可访问性特性**：
- **ARIA 属性**：`role="dialog"`, `aria-modal="true"`, `aria-labelledby`
- **键盘导航**：
  - `Esc` - 关闭抽屉
  - `←/→` - 上一个/下一个单词
  - `Space` - 播放发音
  - `Tab` - 在抽屉内循环导航
- **焦点管理**：打开时自动聚焦，关闭时恢复焦点
- **动画减弱**：支持 `prefers-reduced-motion` 媒体查询

**性能优化**：
- **内存管理**：完善的 destroy() 方法清理所有资源
- **事件清理**：所有事件监听器可追踪和移除
- **动画取消**：requestAnimationFrame 和 setTimeout 统一清理
- **数据缓存**：LRU 缓存机制（50词限制）
- **防抖存储**：批量存储操作，1秒防抖延迟

**使用示例**：
```javascript
const drawer = new WordDrawerV2({
  onClose: () => {
    console.log('Drawer closed');
  },
  onStar: (word, isStarred) => {
    console.log(`${word} starred: ${isStarred}`);
  },
  onDelete: (word) => {
    console.log(`${word} deleted`);
  },
  onNavigate: (direction, currentIndex) => {
    console.log(`Navigated ${direction} to index ${currentIndex}`);
  }
});

// 设置单词列表（用于导航）
drawer.setWordList(wordList);

// 显示单词
drawer.show(wordData, 0);

// 销毁（重要：防止内存泄漏）
```
